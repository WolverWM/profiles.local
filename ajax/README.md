# Profiles — локальная социальная сеть-портфолио

Курсовая работа «Профили пользователей». Мини-социальная сеть, где пользователи
создают профиль-портфолио, публикуют посты (текст + изображение), настраивают
внешний вид страницы (цвета, размер сетки) и подписываются друг на друга.

Стек: PHP 7.4+ (без фреймворков и классов, всё на функциях), MySQL 5.7+ / MariaDB,
чистый JavaScript (ES6, без библиотек, кроме Chart.js и Font Awesome с CDN),
глассморфизм на CSS.

## Установка и запуск (OpenServer / XAMPP / любой Apache+MySQL)

1. Скопируйте содержимое этой папки в `domains/profiles` (OpenServer) или
   `htdocs/profiles` (XAMPP).
2. Создайте базу данных и импортируйте дамп `sql/database.sql` через
   phpMyAdmin (файл сам создаёт базу `profiles_db`, если её ещё нет).
3. Откройте [includes/config.php](includes/config.php) и при необходимости
   поправьте `DB_HOST` / `DB_USER` / `DB_PASS` под ваш сервер (по умолчанию
   `localhost` / `root` / без пароля — подходит для OpenServer и XAMPP «из коробки»).
4. Запустите сервер и откройте сайт в браузере
   (`http://profiles.local/` для OpenServer или `http://localhost/profiles/` для XAMPP).
5. Папки `uploads/avatars/` и `uploads/posts/` должны быть доступны на запись —
   на Windows это обычно работает без дополнительной настройки.

## Тестовый вход

| Логин | Пароль     | Роль  |
|-------|-----------|-------|
| admin | password  | admin |

Администратор может удалять любые посты и пользователей (кнопки появляются
в личном кабинете в разделе «Админ-панель» и в модальном окне поста).
Обычные пользователи регистрируются через страницу [register.php](register.php).

## Структура проекта

```
index.php, profile.php, dashboard.php, login.php, register.php, logout.php,
add_post.php, edit_post.php, delete_post.php, followers.php, following.php, 404.php
includes/   — конфиг, подключение к БД, сессии, CSRF, вспомогательные функции, шапка/подвал
ajax/       — обработчики без перезагрузки страницы (лайки, подписки, поиск, модалка поста,
              drag-and-drop, туториал, статистика для графика)
assets/     — CSS, JS, изображение по умолчанию
uploads/    — сюда сохраняются загруженные аватары и картинки постов (изначально пусто)
sql/        — дамп базы данных
```

## Если проект не запускается — 3 частые причины

1. **Не подключается БД.** В `includes/config.php` параметр `DB_HOST` должен
   совпадать с настройками вашего сервера. Для OpenServer иногда нужно вписать
   не `localhost`, а имя модуля MySQL (смотрите на вкладке «Модули» в OpenServer,
   например `MySQL-8.4`).
2. **Ошибка при импорте `database.sql`.** Убедитесь, что версия MySQL — 5.7+ или
   MariaDB 10.2+. Если сервер старый и не поддерживает `utf8mb4`, замените
   `utf8mb4` на `utf8` в начале файла дампа.
3. **Аватары/картинки не загружаются.** Проверьте, что у папок `uploads/avatars/`
   и `uploads/posts/` есть права на запись для веб-сервера, и что в `php.ini`
   значения `upload_max_filesize` и `post_max_size` не меньше 5M.
